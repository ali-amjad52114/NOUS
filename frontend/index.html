How we built it

Under the hood

Four sponsor stacks, each doing the job it's best at. None of them are decorative.

you say something→ LaserData streams it→ FalkorDB remembers it→ Guild agents check it→ RocketRide executes it
Memory

FalkorDB

Every person, promise, and learned protocol lives as a node in a live graph. The brain reads and writes it on every single interaction.

Used for: the entire memory layer. The Memory graph button opens the raw database so you can watch it grow in real time.
Execution

RocketRide

Each skill Nous learns compiles into a .pipe pipeline. When a protocol fires, the RocketRide engine is the thing actually doing the work.

Used for: a custom Nous node plus generated pipelines per learned skill. The engine calls back into the brain's allowlisted actions.
Judgment

Guild.ai

Two agents watch over the brain: a distiller that turns observed behavior into a typed protocol, and a critic that refuses anything unsafe.

Used for: the human-in-the-loop gate. Nothing runs on your behalf until you approve it once.
Senses

LaserData

Every event in your life stream is published to Laser Stack the moment it happens, so the brain never works from stale information.

Used for: the real-time event feed. Messages, invoices, and calendar changes arrive as a stream, not a batch.
